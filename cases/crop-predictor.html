Crop Predictor

Machine Learning Web Application

Back to Home

Overview

Crop Predictor is a Flask-based machine learning web application that recommends suitable crops based on soil and environmental parameters, enabling data-driven agricultural decisions.

Source Code: View on GitHub

Approach

  • Machine Learning model: K-Nearest Neighbors (KNN)
  • Inputs: N, P, K, pH, rainfall, humidity, temperature
  • Model integrated into a Flask-based web interface

Impact

The application helps farmers select optimal crops based on environmental conditions, improving productivity and reducing guesswork in cultivation.
