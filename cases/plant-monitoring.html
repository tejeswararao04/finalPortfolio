Overview

A year-long engineering project developed under the guidance of Dr. K.S. Deepthi (HoD), focused on automating irrigation and fertilization decisions using IoT sensor data and machine learning.

Problem Statement

Manual irrigation and fertilization often lead to inefficient resource usage and inconsistent crop health. There is a need for a data-driven system that can make timely and accurate decisions.

System Architecture

  • Soil sensors capturing N, P, K values and moisture levels
  • Data preprocessing and feature preparation layer
  • Machine learning-based decision model
  • Web interface for monitoring and control

Machine Learning Approach

Implemented a neural-network-based prediction model using NPK and soil moisture data, achieving 91.2% validation accuracy for irrigation and fertilization decisions, with inference deployed via Flask.

Tech Stack

  • Python, Flask (inference deployment)
  • Neural Networks (91.2% validation accuracy)
  • NPK and soil moisture sensing
  • HTML, CSS
  • IoT Sensors

Validation and Learnings

The system was validated in real-world conditions, highlighting challenges such as sensor noise, data reliability, and hardware-software integration. The project strengthened my understanding of end-to-end ML system deployment.
